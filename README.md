# 🌱 Real-Time Crop Disease Detection

An AI-based web application that analyzes crop leaf images and predicts possible plant diseases.

## Features

- 📷 Upload crop leaf images
- 🤖 AI-based image classification
- 🔍 Disease/health prediction
- 📊 Confidence score
- 📈 Top 3 predictions
- 🌾 Recommended action
- ⚠️ Educational-use disclaimer

## Technologies

- Python
- Streamlit
- PyTorch
- Transformers
- Pillow

## How to Run

Double-click `run.command` to start the application.

## Disclaimer

This project is developed for educational and demonstration purposes. AI predictions should not be considered a professional agricultural diagnosis.
